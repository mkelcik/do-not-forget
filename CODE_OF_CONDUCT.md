# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the
work. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or
any other project space.

Report unacceptable behaviour privately to the maintainer through
[GitHub's private reporting](https://github.com/mkelcik/do-not-forget/security/advisories/new)
or by contacting [@mkelcik](https://github.com/mkelcik) on GitHub. Reports are handled
confidentially. The maintainer may remove content and block participants who break this code.
